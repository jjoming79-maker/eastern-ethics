/** @OnlyCurrentDoc */ /** * 중꺾사 점수 기록 코드 * 이 코드는 선생님의 구글 시트 안에서만 동작합니다. * 학생 이름과 점수는 이 시트의 '기록' 탭에 저장됩니다. * 수업과 시상이 끝나면 '기록' 탭의 2행부터 지워 주세요. */ var JKK_TAB = '기록'; var JKK_HEAD = ['기록 시각', '수업', '이름', '총점', '도전 횟수', '사상가1', '점수1', '사상가2', '점수2', '사상가3', '점수3', '기록번호']; var JKK_THINKERS = ['공자', '맹자', '순자', '주희', '왕수인', '노자', '장자', '석가모니']; var JKK_CACHE_SECONDS = 8; function doGet(e) { var p = (e && e.parameter) || {}; if (p.action === 'ping') return jkkJson_({ ok: true, app: 'jungkkeoksa', version: 2 }); if (p.action === 'ranking') { var cls = String(p['class'] || ''); if (!jkkValidClass_(cls)) return jkkJson_({ ok: false, error: 'bad_class' }); return jkkJson_({ ok: true, ranking: jkkCachedRanking_(cls) }); } return jkkJson_({ ok: false, error: 'bad_action' }); } function doPost(e) { var body; try { body = JSON.parse(e.postData.contents); } catch (err) { return jkkJson_({ ok: false, error: 'bad_json' }); } var problem = jkkValidate_(body); if (problem) return jkkJson_({ ok: false, error: problem }); var lock = LockService.getScriptLock(); if (!lock.tryLock(20000)) return jkkJson_({ ok: false, error: 'busy', retry: true }); try { var sheet = jkkSheet_(); var rows = jkkRows_(sheet); var alreadySaved = rows.some(function (r) { return String(r[11]) === body.id; }); var attempts = rows.filter(function (r) { return String(r[1]) === body['class'] && String(r[2]) === body.name; }); var previousBest = attempts.reduce(function (best, r) { return Math.max(best, Number(r[3]) || 0); }, -1); if (!alreadySaved) { var row = [new Date(), body['class'], body.name, body.score, attempts.length + 1]; body.rounds.forEach(function (x) { row.push(x.thinker, x.score); }); row.push(body.id); var next = sheet.getLastRow() + 1; if (next > sheet.getMaxRows()) sheet.insertRowsAfter(sheet.getMaxRows(), 200); // '3-1' 같은 수업 이름이 날짜로 바뀌지 않도록 글자 형식으로 저장한다. sheet.getRange(next, 2, 1, 2).setNumberFormat('@'); sheet.getRange(next, 1, 1, row.length).setValues([row]); rows.push(row); } jkkClearCache_(body['class']); var ranking = jkkRanking_(rows, body['class']); var mine = ranking.filter(function (x) { return x.name === body.name; })[0]; return jkkJson_({ ok: true, rank: mine ? mine.rank : null, best: mine ? mine.score : body.score, participants: ranking.length, isNewBest: !alreadySaved && body.score > previousBest }); } finally { lock.releaseLock(); } } function jkkValidate_(b) { if (!b || typeof b !== 'object') return 'bad_body'; if (!jkkValidClass_(String(b['class'] || ''))) return 'bad_class'; if (!/^[가-힣]{2,5}$/.test(String(b.name || ''))) return 'bad_name'; if (!/^[A-Za-z0-9-]{8,40}$/.test(String(b.id || ''))) return 'bad_id'; if (typeof b.score !== 'number' || Math.floor(b.score) !== b.score || b.score < 0 || b.score > 39) return 'bad_score'; if (!Array.isArray(b.rounds) || b.rounds.length !== 3) return 'bad_rounds'; var sum = 0, seen = {}; for (var i = 0; i < 3; i++) { var x = b.rounds[i] || {}; if (JKK_THINKERS.indexOf(x.thinker) < 0 || seen[x.thinker]) return 'bad_rounds'; if (typeof x.score !== 'number' || Math.floor(x.score) !== x.score || x.score < -999 || x.score > 13) return 'bad_rounds'; seen[x.thinker] = true; sum += x.score; } return sum === b.score ? '' : 'bad_rounds'; } function jkkValidClass_(c) { return /^[가-힣A-Za-z0-9][가-힣A-Za-z0-9 ·_-]{0,19}$/.test(c); } function jkkSheet_() { var book = SpreadsheetApp.getActiveSpreadsheet(); var sheet = book.getSheetByName(JKK_TAB); if (!sheet) { sheet = book.insertSheet(JKK_TAB); } // 탭을 새로 만들었거나 제목 줄까지 지운 경우 제목 줄을 다시 넣는다. if (sheet.getLastRow() === 0) { sheet.appendRow(JKK_HEAD); sheet.setFrozenRows(1); } return sheet; } function jkkRows_(sheet) { var count = sheet.getLastRow(); if (count < 2) return []; return sheet.getRange(2, 1, count - 1, JKK_HEAD.length).getValues(); } function jkkRanking_(rows, cls) { var best = {}; rows.forEach(function (r) { if (String(r[1]) !== cls || !r[2]) return; var score = Number(r[3]) || 0; var time = new Date(r[0]).getTime(); var old = best[r[2]]; if (!old || score > old.score || (score === old.score && time < old.time)) { best[r[2]] = { name: r[2], score: score, time: time }; } }); return Object.keys(best) .map(function (k) { return best[k]; }) .sort(function (a, b) { return b.score - a.score || a.time - b.time; }) .map(function (x, i) { return { rank: i + 1, name: x.name, score: x.score }; }); } function jkkCacheKey_(cls) { return 'rank_' + Utilities.base64EncodeWebSafe(cls); } function jkkClearCache_(cls) { CacheService.getScriptCache().remove(jkkCacheKey_(cls)); } function jkkCachedRanking_(cls) { var cache = CacheService.getScriptCache(); var key = jkkCacheKey_(cls); var hit = cache.get(key); if (hit) return JSON.parse(hit); var ranking = jkkRanking_(jkkRows_(jkkSheet_()), cls); cache.put(key, JSON.stringify(ranking), JKK_CACHE_SECONDS); return ranking; } function jkkJson_(data) { return ContentService.createTextOutput(JSON.stringify(data)).setMimeType(ContentService.MimeType.JSON); }
